设计尺寸 720×1280 ≠ 玩家看到的尺寸

游戏每一张巡检图、每一个评审页都是 720×1280 的 1:1 —— 那是设计尺寸。 源码实测（resizeCanvas）：画布内部恒为 720×1280(×dpr)，CSS 尺寸按窗口 letterbox ⇒ 一个逻辑 px = cssW/720 个 CSS px。手机 CSS 宽 360 时整幅缩到 0.5， 于是 12px 逻辑字只剩 6 CSS px；按参考机（1080p / 6.1" / DPR3 / dprCap2）折成物理长度是 1.13mm，而中文可读下限约 2.5mm。
